Now we want to train a pairwise generative (thinking) reward model (essentially a policy model, just trained on human preference data) along with a scalar critic model. For both models, we want to start with Qwen/Qwen3-4B-Thinking-2507 model (note that this is a thinking model) from Huggingface, and nvidia/HelpSteer3 data, the preference subset (details in think_rm/helpsteer3.md). We should expand the individual_preference in the dataset, which is a list of dicts, each containing a score for this specific response pair. We assign binary reward during RL training, 1 if the sign matches and 0 if it does not match. During RM training, we should use RLOO style of advantage estimation, but simultaneously train a critic model using the MC rollouts. We hope that this critic model, which assigns a scalar score at the EOS token of generative RM's output, can predict the probability that the RM's final prediction is correct, i.e., the predicted preference matches the label. You should put your code under the recipe/think_rm folder. After that, create a job submission script in the submit folder. You can refer to scripts therein for format.
